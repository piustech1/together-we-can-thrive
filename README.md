# Together We Can Thrive

> Providing a Brighter Future for Africa's Children

**Together We Can Thrive** is a high-fidelity web platform for community relief and sustainable development across Africa. Dedicated to supporting local African charities and NGOs providing clean water, healthcare, food sustainability, education, and orphan care.

## Core Features
- **Hero & Mission**: Video background showcasing clean water and community transformation.
- **Water is Life**: Clean water initiative showcase with responsive media and calls to action.
- **Featured Programs**: 6 core programs across education, healthcare, orphan care, agriculture, school meals, and income generation.
- **Where We Work (Interactive Africa Map & Overlay Filter)**: Standalone vector Africa map with active country highlights (Cameroon, Chad, DRC, Ethiopia, Kenya, Malawi, Rwanda, Sierra Leone, Tanzania, Uganda, Zambia, Zimbabwe), interactive overlay cards with field metrics and partner quotes, and filter pills.
- **Our Partners**: Spotlight on trusted local African organizations and community-led initiatives.
- **Latest News & Impact**: Field reports with stories of change and transformation.
- **Donation Platform**: Unified monthly and one-time donation forms with IRS 501(c)(3) tax deduction support.
- **Social Feeds**: Responsive 3-column feed synced with field stories, like counters, comment sharing, and load more functionality.

## Tech Stack
- HTML5 / Modern Semantic Web
- CSS3 / Custom Variables & Responsive Grid
- Modern ES6+ JavaScript
- Zero external build dependencies (ultra-fast, lightweight static deployment)
